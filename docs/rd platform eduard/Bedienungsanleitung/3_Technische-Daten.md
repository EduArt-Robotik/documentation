# Technische Daten

Nachfolgend finden Sie eine Übersicht der wichtigsten technischen Eckdaten der Schulungsplattform **Eduard Performance V3** in der beschriebenen Grundkonfiguration.  
Die Werte können durch Benutzererweiterungen oder kundenspezifische Anpassungen abweichen.

---

## Mechanische Daten

| Parameter | Wert / Beschreibung |
|------------|----------------------|
| **Eigengewicht** | ca. 6,8 kg |
| **Nennmoment Antriebsstrang (Ausgangsseitig)** | 0,89 Nm |
| **Nenndrehzahl Antriebsstrang (Ausgangsseitig)** | 62 U/min |
| **Maximalgeschwindigkeit (Offroad)** | $v_{\text{max,O}} = 62\,\frac{1}{\text{min}} \cdot \pi \cdot 0.173\,\text{m} \cdot \frac{1\,\text{min}}{60\,\text{s}} = 0.56\,\frac{\text{m}}{\text{s}}$ |
| **Maximalgeschwindigkeit (Mecanum)** | $v_{\text{max,M}} = 62\,\frac{1}{\text{min}} \cdot \pi \cdot 0.1\,\text{m} \cdot \frac{1\,\text{min}}{60\,\text{s}} = 0.32\,\frac{\text{m}}{\text{s}}$ |
| **Abmessungen (L × B × H)** | ca. 420 mm × 400 mm × 210 mm |
| **Lautstärke** | 66 dB(A) |


:::info
Die Maximalgeschwindigkeiten wurden aus der Nenndrehzahl und dem jeweiligen Raddurchmesser berechnet.  
Offroad = Ø 173 mm, Mecanum = Ø 100 mm.
:::
