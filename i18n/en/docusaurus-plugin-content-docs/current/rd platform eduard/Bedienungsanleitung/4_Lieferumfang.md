# Scope of Delivery

The scope of delivery for the **Eduard Performance V3** training platform includes the following components:

- 1 robot in the ordered configuration  
  *(e.g., with controller, router, etc.)*
- Optional additional wheel set
- Hex socket wrench (2.5 mm)
- Storage rack
- Charger (P/N: SW4327C)
- Spare parts kit
