# Technical Data

Below you will find an overview of the most important technical specifications of the training platform **Eduard Performance V3** in the described basic configuration.
The values may deviate due to user extensions or customer-specific customizations.

---

## Mechanical Data

| Parameter | Value / Description |
|------------|----------------------|
| **Gross Weight** | approx. 6.8 kg |
| **Nominal Torque Drivetrain (Output Side)** | 0.89 Nm |
| **Nominal Speed Drivetrain (Output Side)** | 62 rpm |
| **Maximum Speed (Off-Road)** | $v_{\text{max,O}} = 62\,\frac{1}{\text{min}} \cdot \pi \cdot 0.173\,\text{m} \cdot \frac{1\,\text{min}}{60\,\text{s}} = 0.56\,\frac{\text{m}}{\text{s}}$ |
| **Maximum Speed (Mecanum)** | $v_{\text{max,M}} = 62\,\frac{1}{\text{min}} \cdot \pi \cdot 0.1\,\text{m} \cdot \frac{1\,\text{min}}{60\,\text{s}} = 0.32\,\frac{\text{m}}{\text{s}}$ |
| **Dimensions (L × W × H)** | approx. 420 mm × 400 mm × 210 mm |
| **Noise Level** | 66 dB(A) |

:::info
The maximum speeds were calculated from the nominal speed and the respective wheel diameter.
Off-road = Ø 173 mm, Mecanum = Ø 100 mm.
:::
